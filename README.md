Product: QueueLess — Digital School Queue System
The V1 will allow students to join a queue for a selected school office and see their position in real time.
Features included:
Student enters their name/ID.
Student selects an available office/queue.
Student receives a queue number.
Student can see their current position.
Office staff can view the active queue.
Staff can call the next student.
Queue status updates automatically.
Basic Supabase database to store students and queue information

Deliberately out of scope for V1:
Payments
Notifications/SMS
Multiple schools
Mobile app
Complex admin system
Analytics
AI features
Appointment booking
Main V1 journey:
Join queue → Get number → Track position → Get called.
